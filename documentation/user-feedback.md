# User Feedback

## Initial Feedback

Informal discussions with hostel students indicated that water wastage can occur due to taps being left open, tank overflow, and lack of continuous monitoring.

## Key Observations

- Students preferred a simple system that can monitor water usage automatically.
- Real-time alerts were considered useful for identifying unusual water consumption.
- A dashboard could help hostel management understand usage patterns.
- The system should be easy to use and should not require constant manual monitoring.

## Feedback-Based Improvements

Based on the observations, the proposed system focuses on:

1. Real-time water usage monitoring
2. Abnormal usage detection
3. Timely alerts
4. Simple dashboard-based visualization
5. Water-saving recommendations

## Current Status

The project is currently at the prototype and validation stage. Further feedback will be collected and used to improve the system.
